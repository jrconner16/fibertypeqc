# Examples

Public demo data are intentionally not included in v0.1-alpha.

This directory is reserved for a future cleared or synthetic demo that can show the
FiberTypeQC workflow without exposing private microscopy data.

Planned demo workflow:

1. Run the pipeline on a small sample image.
2. Inspect generated fiber CSV and batch summary.
3. Open the review UI on the sample outputs.
4. Merge a small review correction table.
